# Runtime dependency audit

## Exact loader choice and evidence limits

**MelonLoader 0.7.3 Windows x64 is the exact experimental pin. Runtime compatibility with TLD 2.55 is not yet proven.** The [official 0.7.3 release](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3) fixes Il2CppAssetBundleManager and Il2CppImageConversionManager for Unity 6000+ (#1122, #1144). This is a concrete reason to use 0.7.3 rather than the compile reference's older loader. The README's Unity 6000.0.60f1 claim still needs verification on the actual game copy.

Compilation uses the existing locked TLD 2.55.0 NuGet snapshot and its **MelonLoader 0.7.1.0** reference. This was not silently presented as a 0.7.3 compile target. A static PE metadata audit resolves the produced DLL's non-framework AssemblyRefs by name and minimum version against the **actual official 0.7.3 archive**, the TLD 2.55 compile snapshot and the shipped Steamworks binding. It does not execute downloaded assemblies. Version resolution alone does not prove method semantics, generated interop correctness, bootstrap success or native ABI behavior. The result is included as runtime-audit.json.

## Distribution and responsibilities

| Dependency | Exact choice / provider | Included? | Verification and remaining gate |
|---|---|---|---|
| SkyCoop.dll and PDB | This source commit, net6.0 | Yes, MIT | Warning-free compile and managed regressions; game behavior untested |
| Steamworks.NET.dll | 20.2.0, Windows x64 managed runtime | Yes, MIT notice | Exact NuGet runtime bytes and assembly identity; native entry points need real game test |
| .NET Desktop Runtime | 6.0.36 Windows x64 official candidate | External Microsoft installer | Official metadata SHA-512 pinned; installed runtime must be checked per seat |
| MelonLoader | 0.7.3 Windows x64 | External full official archive | Archive SHA-256 verified; direct loader/interop/Harmony AssemblyRefs resolved statically |
| Harmony, Il2CppInterop, loader's support DLLs | Preserve the full 0.7.3 distribution | With external loader | Do not replace with NuGet build references or older separate libraries |
| Game/Unity/Il2CppTLD interop | Generated by loader from the actual legal 2.55 install | External game-generated files | Compile snapshot only available here; compare actual regenerated APIs and patch results in game |
| Native steam_api64.dll | The game's own Windows x64 library | External game file | Never redistributed/replaced; exported ABI remains untested |
| multiplayerstuff.unity3d | Compatible validated rebuild not available | External | Official legacy header 2018.4.21f1; real Unity 6 load and prefab/component checks pending |
| SkyCoop.modcomponent | Migrated compatible item pack not available | External | Confirmed path/Addressables migration blocker; embedded bundle 2018.4.2f1 |
| ModComponent | dommrogers 7.0.0 migration candidate, release targets TLD 2.51 | External, unvalidated | Not compatible with original pack layout; 2.55 API behavior unverified |
| ModSettings | 1.9.0 candidate for ModComponent 7 | External, unvalidated | Release targets TLD 2.06/ML0.6.0; require real 2.55 verification |

No extra TinyJSON library is needed: its source is already compiled into SkyCoop. No Co-op Anything runtime is needed. GearSpawner/CraftingRevisions/LocalizationUtilities are merged into modern ModComponent 7.0.0; do not add obsolete separate copies based on older setup guides. ModComponent may fetch its own dependency metadata at startup; include an offline-startup test.

MelonLoader's license is Apache-2.0 and it carries components under other licenses, including LGPLv3 Il2CppInterop. The full official loader is obtained separately to retain its complete distribution and notices. SkyCoop's source MIT license does not automatically establish rights over every bundled third-party art/audio asset. Accordingly neither legacy game/mod assets nor game-generated NuGet reference DLLs are redistributed in this artifact.

## Commands

```
python3 tools/verify_runtime.py
python3 tools/inspect_assets.py
```

The first verifies the official loader archive hash and static AssemblyRef providers; the second hashes/inspects the official legacy asset archive and its nested component. They write machine-readable reports and never mark the mod playable. System.* references still require an installed .NET6 runtime, and native/game dependencies remain external.
