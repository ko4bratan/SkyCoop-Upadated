# Steam и игровое меню: экспериментальная интеграция 2.55

Продолжена ветка port/tld-2.55-audit; старые исходники, UDP/Radmin, launcher и renderer Reborn сохранены. Это ещё не восстановленный полный кооператив 2.01–2.02. Запуск меню, Steam overlay, relay/P2P, два клиента и native UI требуют реальной игры. Ни облачные тесты, ни компиляция этого не подтверждают.

## Что теперь делает мод

При обычном запуске без аргументов включается безопасный режим с отдельным сетевым маршрутом. Штатный BasicMenu получает кнопку «МУЛЬТИПЛЕЕР / MULTIPLAYER». В подменю используются игровой BasicMenu и штатный Panel_Confirmation для IPv4; добавлены создание lobby Steam, приглашение, открытие друзей/принятие приглашения в Steam overlay, UDP host/join, просмотр статуса, сброс сеанса и возврат. Обработчики работают с реальной Steam API, а не имитируют успех. Внешний вид, фокус клавиатуры, расположение и повторный вход в панели пока проверены только по коду/API, визуально в игре — НЕТ.

Сверен [исходный SteamConnect.cs, BeforeTFTFT/c3e5d76](https://github.com/Filigrani/SkyCoop/blob/c3e5d7686da4d581012a8290e44330b7e2a4e427/SteamConnect.cs): там уже есть CreateLobby, JoinLobby, GameLobbyJoinRequested, ActivateGameOverlayInviteDialog и reliable legacy P2P. Используются существующие Steamworks.NET20.2.0, resolver системной библиотеки игры и SteamMatchmaking/SteamNetworking, уже применявшиеся SkyCoop. Native steam_api64.dll не поставляется и не заменяется. Лобби friends-only на2 участников содержит protocol/target/DLL hash. Приглашения GameLobbyJoinRequested и +connect_lobby обрабатываются отдельно от старых UI/assets. Steam overlay открывается настоящими SteamFriends API. Для этого клиент Steam, нужный AppID305620, overlay и рабочий native SDK обязательны; конкретный ABI на ПК ещё не проверен.

В Steam используется отдельный канал17 legacy P2P с проверкой членства в lobby и выбранного peer. Пакеты минимального режима9055/9056 проходят ограниченный envelope; старые RPC мира/инвентаря на этот маршрут не допускаются. UDP26950/26951 сохранён отдельным вариантом. Ошибка Steam callbacks отключает Steam-обработку диагностически; UDP-код не заменяется. Автоматическое переключение активного сеанса со Steam на UDP не выполняется.

Позиции, yaw, crouch/run, интерполяция и Reborn renderer продолжают работать по существующему минимальному протоколу. При timeout сбрасываются nonce/remote snapshots, освобождается UDP-слот, гостевой клиент повторяет handshake. Выход из lobby очищает сеанс; host migration не реализована. Это реализация восстановления, ещё не проверенная при реальной потере сети. Кнопка сброса позволяет выбрать роль заново.

## Установка в существующую Steam-папку

Вторая загрузка игры не требуется. Автопоиск читает существующие Steam libraries. Лаунчер теперь имеет кнопку «Установить и открыть через Steam», запускающую steam://run/305620 после проверки выбранной Steam-папки. Обычное игровое меню — основной путь; старые две кнопки launcher остаются резервным UDP-путём.

Перед установкой проверяются tld.exe, соответствие appmanifest_305620.acf выбранной папке, версия игры, MelonLoader0.7.3 и хеши устанавливаемых DLL. При существующих файлах мода — запрос замены, по умолчанию отказ; предыдущие файлы сохраняются в SkyCoop-Backups. Мод не удаляет/переносит сохранения, не меняет Steam branch, не откатывает игру и не заменяет native DLL или loader. Steam сохранения могут синхронизироваться самим Steam; используйте отдельный тестовый слот в обычном профиле и сделайте резервную копию важных сохранений самостоятельно. Vanilla-игра всё равно может записывать свой save при игре.

**Точный блокер автоматической проверки версии:** файловая версия tld.exe нередко является версией Unity, а Steam buildid не даёт достоверного соответствия2.55 без проверенной таблицы. Поэтому неизвестная версия блокирует запись. Принимается либо явная ProductVersion2.55, либо game-identity.json, полученный модом при запуске: Application.version2.55 и совпадающий SHA256 именно этого tld.exe. После обновления exe старое подтверждение отклоняется. Нельзя вручную подделывать этот JSON. Для первого пользователя без такого отчёта и с Unity-версией в PE автоматическая установка останется заблокированной: нужен дополнительный надёжный reader game metadata/проверенный Steam build mapping. Такой mapping здесь не выдуман. Установка MelonLoader пока направляется инструкцией; автоматическая установка loader не реализована.

Если версия подтверждена: распаковать ZIP, открыть «Открыть-SkyCoop.cmd», выбрать Steam-папку, установить loader по инструкции при необходимости, отметить использование тестового сохранения и нажать кнопку Steam. Для работы не нужны ручные PowerShell-команды. После запуска нажать «МУЛЬТИПЛЕЕР», создать Steam lobby, пригласить друга; другу принять приглашение. Затем обоим вручную загрузить disposable копии одного тестового мира с одинаковым seed и сценой. Автоматическая загрузка/передача мира не реализована.

## Матрица совместимости

| Подсистема | Состояние исходников | Что не подтверждено / блокирует |
|---|---|---|
| UDP host/guest, координаты/yaw | Реализовано, managed protocol/loopback тесты | Два реальных клиента и повторное подключение |
| Steam lobby/friends/invite | Новая обвязка существующих SDK/API | Native ABI, overlay, accept invite, NAT/relay на двух Steam-аккаунтах |
| Игровая кнопка и навигация | Штатные BasicMenu/Panel_Confirmation, выборочные Harmony hooks | Жизненный цикл, визуальный стиль, фокус клавиатуры в игре |
| Disconnect/reconnect | Cleanup, nonce reset, освобождение слота, повтор handshake | Реальная потеря сети/выход хоста/повторный вход |
| Reborn персонаж | Loader, validation, renderer, interpolation, marker fallback | Unity export НЕ выполнен; shader/rig/native load/права на выбранные assets |
| Idle/Walk/Crouch/Run | Параметры Animator передаются | Run — ускоренный Walk; отдельного клипа нет; визуально не проверено |
| Pickup/drop, инвентарь | Старый код сохранён, минимальным режимом не включён | Нужен аудит authority/дубликатов/потери вещей на2.55 |
| Контейнеры, двери | Старые RPC/patches сохранены | GUID/сцены, конфликт операций, актуальные API и game QA |
| Огонь, приготовление | Старые реализации сохранены | Время, ownership, serialize/restore, безопасная синхронизация |
| Сон и ускорение времени | Старый код сохранён | Согласование времени обоих игроков, сохранения |
| Wildlife | Старый код сохранён | AI authority, animation/navmesh, актуальный runtime |
| Урон/здоровье | Старый код сохранён | Rig contract, authoritative events, повторы/потери пакетов |
| Общий мир/сохранения | НЕ включены в новый маршрут | Транзакционность, восстановление, persistence; game QA отсутствует |
| Legacy assets/ModComponent | Старые bundles проинвентаризированы | Старый item pack требует Addressables migration, лицензированного rebuild |

Не перечислены вымышленные конкретные API-ошибки: для большинства legacy gameplay-подсистем подтверждённого изменения метода2.55 пока нет. Их совместимость остаётся неизвестной, а не объявляется сломанной только из-за возраста исходников. Полный старый путь можно явно выбрать -skycoop-legacy исключительно для отдельного аудита: это не рекомендация включать его на ценных сохранениях.

## Проверки на Windows и двух клиентах

1. Зафиксировать Steam AppID/buildid, версию игры, Unity, loader, SHA256 exe/DLL/bundle. Не принимать старый Player.log за результат текущего запуска.
2. Проверить main menu: одна кнопка, мышь/стрелки/Enter/Escape, Back, повторное открытие, загрузка/выгрузка сцены. При ui.attach/ui.multiplayer-open сохранить полный лог; успешная компиляция не доказывает этот этап.
3. Создать lobby; открыть список друзей и реальный invite dialog. Отключённый overlay должен дать понятный статус. Принять приглашение при запущенной игре и отдельно при запуске через +connect_lobby.
4. Загрузить одинаковый тестовый мир на обоих ПК, проверить двусторонние координаты/crouch/run. Другой DLL hash/seed должен отклоняться. Чужой пользователь не должен отправлять пакеты вне lobby.
5. Проверить выход гостя, повторный вход, выход хоста, отключение VPN/сети, timeout, ручной сброс. Host migration не ожидать.
6. Отдельно проверить UDP/Radmin. Не считать рабочий UDP доказательством Steam relay. Общие предметы и сохранения пока не проверять как реализованный функционал.
7. Сохранить обоим пользователям MelonLoader/Player logs, structured diagnostics и скриншоты UI. Лаунчер собирает локальный ZIP, не отправляя его автоматически.

Для этих проверок нужны Windows, лицензированная Steam-установка и два реальных клиента/аккаунта. Для персонажа отдельно нужен Unity Editor и подтверждение лицензий ресурсов. В облаке этого нет. Поэтому конечная цель полного Survival-кооператива пока НЕ достигнута.
